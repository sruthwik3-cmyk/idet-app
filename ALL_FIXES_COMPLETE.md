## 🎯 How to Use Each Feature

### Edit a Document:
1. Go to Dashboard OR Document Files page
2. Find the document
3. Click the **Edit button** (✏️)
4. Change expiry date or other details
5. Save changes

### Delete a Document:
1. Go to Dashboard OR Document Files page
2. Find the document
3. Click the **Delete button** (🗑️)
4. Confirm deletion
5. Document and file are removed

### Download a File:
1. Go to Dashboard OR Document Files page
2. Find document with "File Attached" badge
3. Click the **Download button** (🔗 or 📥)
4. File opens in new tab

### View All Files:
1. Click **"Document Files"** in sidebar
2. See all uploaded files in gallery
3. Search or filter as needed
4. Click any button to interact
