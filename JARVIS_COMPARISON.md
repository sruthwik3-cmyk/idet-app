## 🔄 Easy Switching

You can switch between modes anytime:

**To Enable AI Mode:**
1. Get OpenAI API key
2. Add to `.env` file
3. Change `AI_MODE_ENABLED = true` in `aiService.ts`
4. Rebuild and deploy

**To Disable AI Mode:**
1. Change `AI_MODE_ENABLED = false`
2. Rebuild and deploy

No data loss, instant switch!
