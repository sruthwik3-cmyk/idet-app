# 🎨 Logo Update Instructions

## Step 1: Save the New Logo

1. **Save Image 2** (the professional IDET logo) to your computer
2. **Rename it to:** `idet-logo.png`
3. **Place it in:** `public/` folder

The file path should be: `public/idet-logo.png`

## Step 2: Run the Build

After saving the logo, I'll update all the code to use it. Then run:

```bash
npm run build
```

## Where the Logo Will Appear

✅ **Login Page** - Main branding
✅ **Landing Page** - Header logo
✅ **Sidebar** - App navigation
✅ **Browser Tab** - Favicon
✅ **Email Alerts** - Email header

## Logo Specifications

- **Format:** PNG with transparent background
- **Recommended Size:** 512x512px or 1024x1024px
- **File Size:** Under 200KB for fast loading
